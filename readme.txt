Plugin is used to assign category to uploaded image through media upload in WordPress.

== Description ==

This plugin basically creates media category functionality through which one can assign media categories to uploaded media in media library and can list them on based of their categories.

== Installation ==

1. Upload the plugin files to the '/wp-content/plugins/' directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
